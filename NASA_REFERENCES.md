## Project license status

No blanket project license has been assigned. Commit metadata does not prove copyright ownership or authority to relicense the original game, and the rights for some carried-forward content are not independently established. `LICENSE` therefore records **pending rights-holder confirmation** instead of silently assigning MIT/Apache to work the requester may not own. Before a public submission or source redistribution, the project owner must select an OSI-approved license for the original code/content and clear third-party asset rights. Dependency licenses do not relicense the project itself.
