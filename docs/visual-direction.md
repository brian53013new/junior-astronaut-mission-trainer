# Visual direction: working operations room

The command room should feel like a practical work station designed for sustained monitoring, not a generic holographic science-fiction cockpit. Use familiar materials (painted steel, matte polymer, brushed aluminum, paper, fabric cable sleeves), functional seams and fasteners, desk-mounted controls, restrained indicator lamps, legible display content, and a large but ordinary observation display. Keep emissive effects to indicators that communicate a state. Avoid NASA logos and mission insignia.

The single player viewpoint is seated at the desk. Mouse movement produces small head-look parallax only; physical desk controls dispatch actions; the remaining on-screen overlays present information, language selection, and tutorial controls. The room should not imply walking, roaming or a level map. Paper procedures and status readouts should support the same decisions as the resource simulation.

## Evidence and interpretation

- NASA's Spaceflight Operations overview describes the Flight Control Room as several staffed discipline consoles supporting flight operations: [NASA Spaceflight Operations](https://www.nasa.gov/reference/jsc-spaceflight-operations/), accessed 2026-11-04.
- NASA's Hubble Mission Operations page describes console operators monitoring systems such as power, thermal, data management and pointing: [Hubble Mission Operations](https://science.nasa.gov/mission/hubble/observatory/mission-operations/), accessed 2026-11-04.
- NASA's active Human-System Standard Volume 2 establishes human-factors requirements for crew interfaces and equipment: [NASA-STD-3001 Volume 2](https://www.nasa.gov/reference/nasa-std-3001v2/), accessed 2026-11-04. We use it only as a high-level reminder to favor readability and clear control feedback; this game is not certified against the standard.
- NASA historical mission-control photographs provide visual reference for rows of functional consoles and large shared displays: [Apollo 16 Mission Control](https://www.nasa.gov/image-article/mission-control-center-during-apollo-16/), accessed 2026-11-04.

**Art inference:** Our single-operator lunar outpost desk, neutral industrial palette and fictional habitat window are a game interpretation of these operations references, not a depiction of an actual NASA facility or approved lunar console. The current build uses procedural geometry; visual finish, readability and interaction still need validation in an actual browser.
